# 多智能体工作流 - 自然语言触发指南

本指南介绍如何通过自然语言对话触发多智能体工作流。

## 🎯 快速开始

在 AI 对话框中，您可以用以下任何一种方式触发工作流：

### 方式 1: 自然语言 🗣️

直接用中文或英文描述您的需求：

```
✅ "请对我的代码运行代码审查"
✅ "执行代码探索"
✅ "质量检查"
✅ "分析一下项目结构"
✅ "运行代码审查工作流"
```

### 方式 2: 斜杠命令 ⌨️

使用快捷命令：

```
✅ /workflow code-review
✅ /code-review
✅ /review
✅ /explore
✅ /quality-check
```

### 方式 3: 指定路径 📁

为特定目录运行工作流：

```
✅ "对 ./components 运行代码审查"
✅ "审查 ./src 目录"
✅ /workflow exploration ./lib
```

## 🔧 工作原理

### 意图识别流程

```
用户输入
    ↓
[1] 斜杠命令检测
    ├─ /workflow → 工作流系统
    ├─ /code-review → 代码审查
    └─ /explore → 代码探索
    ↓
[2] 自然语言关键词检测
    ├─ "代码审查" → code_review
    ├─ "探索代码" → exploration
    └─ "质量检查" → quality_check
    ↓
[3] 置信度评分
    ├─ 精确匹配: 1.0
    ├─ 包含动词: 0.9
    └─ 关键词匹配: 0.7
    ↓
[4] 执行工作流
    ↓
返回结果和进度
```

### 置信度阈值

- **≥ 0.6**: 自动执行工作流
- **< 0.6**: 显示可用工作流列表
- **精确匹配**: 立即执行（置信度 1.0）

## 🚨 常见问题

### Q: 如何知道工作流是否在运行？

**A**: 工作流启动后，您会收到确认消息，并且可以：
- 在"执行监控"标签页查看实时进度
- 在"已完成工作流"列表查看历史记录
- 通过状态图标了解执行状态

### Q: 可以同时运行多个工作流吗？

**A**: 可以！系统支持并行执行多个工作流，每个工作流都有独立的 ID 和状态追踪。

### Q: 工作流执行失败了怎么办？

**A**: 系统会显示详细的错误信息，您可以：
- 查看错误日志了解失败原因
- 修复问题后重新运行
- 使用"重试"按钮快速重试

### Q: 如何停止正在运行的工作流？

**A**: 在执行监控面板中，您可以：
- 点击"停止"按钮终止工作流
- 关闭监控面板（工作流会在后台继续运行）

### Q: 自然语言识别不准确怎么办？

**A**: 您可以：
- 使用更明确的表达方式
- 使用斜杠命令（100% 准确）
- 包含更多上下文信息
