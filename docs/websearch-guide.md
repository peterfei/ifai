# WebSearch Agent 使用指南

## 概述

WebSearch Agent 是 IfAI 的智能网络搜索助手，可以帮你搜索最新信息、查找技术文档、获取实时数据。

## 快速开始

### 基本用法

在 TUI 或 CLI 中，直接用自然语言提问：

```
你: 搜索历史上的今天
你: 查找最新的 React 版本
你: 网络搜索 Rust 异步编程最佳实践
你: 帮我搜一下 Python 3.12 的新特性
```

### 系统会自动

1. 识别你的搜索意图
2. 调用 websearch_agent
3. 执行智能搜索
4. 分析和综合结果
5. 返回格式化的答案

**无需手动选择工具，也无需审批！**

## 搜索能力

### 支持的搜索类型

| 搜索类型 | 示例 |
|---------|------|
| 技术文档 | "搜索 Rust async book" |
| 最新版本 | "查找最新的 Node.js 版本" |
| 历史事件 | "历史上的今天发生了什么" |

### 智能特性

- **多轮搜索**：自动优化查询关键词
- **结果过滤**：智能过滤低质量结果
- **内容综合**：从多个来源提取关键信息
- **缓存优化**：相同查询快速返回（1 小时缓存）

## 高级用法

### 搜索策略

1. **明确目标**：具体描述你想要什么
   - ✅ 好："搜索 Rust 异步编程中的 Pin 和 Future"
   - ❌ 差："搜索 Rust 异步"

2. **使用关键词**：包含技术术语或版本号
   - ✅ 好："搜索 React 18 并发模式"
   - ❌ 差："搜索 React 新特性"

3. **指定来源**（可选）：如果知道具体来源
   - "搜索 Rust 官方文档关于 async 的部分"

## 配置

### API Key

WebSearch Agent 使用博查 AI（Bocha AI）搜索引擎：

1. 访问 https://open.bochaai.com/
2. 注册并获取 API Key
3. 将 API Key 添加到项目根目录的 `.env` 文件：
   ```
   BOCHA_API_KEY=sk-your-api-key-here
   ```

### 缓存配置

搜索结果自动缓存到：
- **位置**：`~/.ifai/cache/search.json`
- **TTL**：1 小时
- **容量**：100 条记录（LRU）

手动清除缓存：
```bash
rm ~/.ifai/cache/search.json
```

## 工作原理

### 架构设计

```
用户提问
   ↓
LLM 识别搜索意图
   ↓
调用 websearch_agent（而非 web_search）
   ↓
Agent 执行智能搜索策略
   ↓
调用底层 web_search 工具
   ↓
博查 AI API 返回结果
   ↓
Agent 分析、过滤、综合
   ↓
返回格式化答案给用户
```

### 为什么使用 Agent 而非直接搜索？

| 特性 | web_search（底层） | websearch_agent（推荐） |
|-----|------------------|----------------------|
| 多轮迭代 | ❌ | ✅ |
| 结果分析 | ❌ | ✅ |
| 智能过滤 | ❌ | ✅ |
| 内容综合 | ❌ | ✅ |
| 适用场景 | Agent 内部使用 | 用户直接调用 |

## 故障排除

### 搜索无结果

1. **检查 API Key**：
   ```bash
   echo $BOCHA_API_KEY
   ```

2. **检查网络连接**：
   ```bash
   curl -I https://api.bocha.cn
   ```

3. **查看日志**：
   ```bash
   tail -f .ifai/debug.log | grep web_search
   ```

### API 限流

博查 AI 有免费额度限制：
- 频繁搜索可能触发限流
- 建议启用缓存（默认开启）
- 考虑升级付费计划

### 搜索结果不准确

**优化方法**：
1. 使用更具体的关键词
2. 包含技术术语或版本号
3. 明确搜索范围（如"官方文档"、"GitHub"）

## 常见问题

**Q: 为什么有时候还是会弹窗审批？**
A: 只有第一次使用或权限过期时才会弹窗，之后会自动通过。

**Q: 搜索结果会保存吗？**
A: 只缓存搜索结果，不保存查询历史。

**Q: 支持哪些搜索引擎？**
A: 目前使用博查 AI（专为 AI 优化的国内搜索引擎）。

**Q: 可以搜索图片或视频吗？**
A: 当前版本仅支持文本搜索，多媒体搜索规划中。

**Q: 搜索失败会怎样？**
A: 系统会返回降级结果（基于缓存或模拟数据），不会中断对话。
