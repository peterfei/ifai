# 工作流浮动监控器功能说明

## 概述

工作流浮动监控器（WorkflowFloatingMonitor）是一个在聊天界面之上显示的实时工作流监控组件，采用浮层设计，不会遮挡聊天内容。

## 设计特点

### 1. 浮层覆盖设计
- **位置**：右下角浮动显示（可拖拽到任意位置）
- **层级**：z-index: 50，确保在所有聊天组件之上
- **背景**：半透明背景（95% 不透明度），背景模糊效果
- **响应式**：自适应窗口大小，限制在窗口范围内

### 2. 交互功能
- **拖拽**：点击标题栏可拖拽到任意位置
- **最小化**：点击最小化按钮，仅显示进度条和基本信息
- **展开**：点击最小化后的卡片可展开完整监控界面
- **关闭**：点击关闭按钮移除监控器
- **多工作流切换**：标签页方式切换多个同时执行的工作流

### 3. 视觉效果
- **渐变标题栏**：蓝色到紫色渐变，视觉吸引
- **状态指示**：
  - 运行中：蓝色，动画脉冲效果
  - 完成：绿色
  - 失败：红色
- **进度条**：实时显示整体进度
- **节点状态卡片**：每个节点的详细状态和输出

## 技术实现

### 组件架构
```
WorkflowFloatingMonitorContainer (容器)
  └─ WorkflowFloatingMonitor (UI)
       ├─ 标题栏（可拖拽）
       ├─ 工作流切换标签
       ├─ 折叠/展开按钮
       └─ WorkflowDAGMonitor (完整监控内容)
            ├─ 状态卡片
            ├─ 进度条
            ├─ DAG 可视化
            ├─ 节点详情
            └─ 时间线日志
```

### 事件监听
监听以下 Tauri 事件：
- `workflow:started` - 工作流启动
- `workflow:completed` - 工作流完成
- `workflow:error` - 工作流错误
- `workflow:progress` - 工作流进度（由 WorkflowDAGMonitor 处理）

### 状态管理
```typescript
interface WorkflowInfo {
  id: string;
  name: string;
  nodes: DAGNode[];
  edges: DAGEdge[];
  status: 'running' | 'completed' | 'failed';
  startTime: number;
}
```

### 自动清理
- 工作流完成 3 秒后自动从列表移除
- 避免内存泄漏和 UI 混乱

## PIVO 3.0 架构契合

这个设计完美契合 PIVO 3.0 的 Chat-Native 理念：

1. **非侵入式**：不修改聊天界面，仅在需要时浮层显示
2. **信息透明**：所有工作流信息实时可见，不需要切换页面
3. **用户控制**：用户可以移动、最小化、关闭监控器
4. **多任务友好**：支持多个工作流同时执行和监控

## 对比传统方案

### 专用页面监控（旧方案）
❌ 需要切换到 /workflows 页面
❌ 看不到聊天上下文
❌ 操作繁琐

### 聊天内嵌监控（备选方案）
❌ 消息很长，影响阅读
❌ 滚动时可能看不见
❌ 无法实时监控

### 浮动监控器（新方案）✅
✅ 始终可见，不影响聊天
✅ 可拖拽、可最小化
✅ 多工作流并行支持
✅ 视觉效果美观
