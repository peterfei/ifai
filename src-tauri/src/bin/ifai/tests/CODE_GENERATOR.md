# 代码生成器文档

## 概述

代码生成器是 CLI 测试框架的核心组件，负责从 YAML 测试定义自动生成 Rust 测试代码。

### 架构

```
YAML 测试定义 → 代码生成器 → Rust 测试代码
    ↓                    ↓              ↓
tests/suite/       build.rs       tests/generated/
*.yaml          generate_tests()      *.rs
```

### 关键组件

| 组件 | 文件 | 功能 |
|------|------|------|
| 生成入口 | `build.rs` | 在构建时调用测试生成 |
| 生成逻辑 | `generate_tests.rs` | 从 YAML 生成 Rust 代码 |
| 生成目录 | `tests/generated/` | 存储生成的测试文件 |
| 源定义 | `tests/suite/` | YAML 测试定义 |

## 工作流程

### 1. 自动生成（推荐）

修改 YAML 文件后，运行 `cargo build` 自动触发生成：

```bash
# 修改 YAML 文件
vim src/bin/ifai/tests/suite/my_test.yaml

# 触发自动生成
cargo build --package ifainew

# 查看生成的代码
cat src/bin/ifai/tests/generated/my_test.rs
```

### 2. 手动生成

使用 `generate_tests` 二进制文件手动生成：

```bash
cargo run --bin generate_tests
```

## 生成过程详解

### Step 1: 读取 YAML

生成器扫描 `tests/suite/` 目录：

```rust
for entry in fs::read_dir("tests/suite")? {
    let path = entry.path();

    if path.extension() == Some("yaml") || path.extension() == Some("yml") {
        // 读取 YAML 内容
        let yaml_content = fs::read_to_string(&path)?;

        // 解析 YAML
        let schema: serde_yaml::Value = serde_yaml::from_str(&yaml_content)?;

        // 生成测试代码
        let test_code = generate_test_from_schema(&schema, &path)?;

        // 写入文件
        fs::write("tests/generated/my_test.rs", test_code)?;
    }
}
```

### Step 2: 解析 YAML Schema

```yaml
test_suite:
  name: "我的测试"
  tests:
    - name: "测试1"
      given:
        args: ["hello"]
```

解析为：

```rust
struct TestSuite {
    name: String,
    tests: Vec<TestCase>,
}

struct TestCase {
    name: String,
    description: Option<String>,
    given: Option<TestGiven>,
    when: Option<TestWhen>,
    then: Option<TestThen>,
}
```

### Step 3: 生成 Rust 代码

```rust
fn generate_test_from_schema(schema: &serde_yaml::Value) -> String {
    let mut code = String::new();

    // 文件头
    code.push_str("// Generated by build.rs\n");
    code.push_str("// DO NOT EDIT MANUALLY\n");
    code.push_str("// Original source: tests/suite\n\n");

    // 导入
    code.push_str("use crate::tests::common::*;\n\n");

    // 生成每个测试
    for test in tests {
        code.push_str(&generate_single_test(test));
        code.push_str("\n");
    }

    code
}
```

### Step 4: 写入文件

```rust
let output_path = "tests/generated/my_test.rs";
fs::write(&output_path, test_code)?;
```

## 代码生成规则

### 1. 函数名生成

测试名称自动转换为有效的 Rust 标识符：

| 中文名称 | 生成的函数名 |
|---------|-------------|
| 帮助命令显示 | `test_bang_zhu_ming_ling_xian_shi` |
| 环境变量优先级 | `test_huan_jing_bian_liang_you_xian_ji` |
| 测试输出 | `test_ce_shu_shu_chu` |
| 测试输出（重复） | `test_ce_shu_shu_chu_2` |

### 2. 拼音映射表

```rust
const PINYIN_MAP: &[(&str, &str)] = &[
    ("帮助", "bang_zhu"),
    ("命令", "ming_ling"),
    ("显示", "xian_shi"),
    ("环境", "huan_jing"),
    ("变量", "bian_liang"),
    ("优先级", "you_xian_ji"),
    ("测试", "ce_shi"),
    ("输出", "shu_chu"),
    // ... 更多映射
];
```

### 3. Given 阶段生成

**YAML**:
```yaml
given:
  args: ["hello"]
  env:
    IFAI_PROVIDER: "openai"
  config: |
    provider: deepseek
  stdin: "yes\n"
```

**生成的代码**:
```rust
let mut env = TestEnv::with_mock().await.unwrap();
env.set_env("IFAI_PROVIDER", "openai");
env.write_config("provider: deepseek\n").await.unwrap();
env.set_stdin("yes\n");
```

### 4. When 阶段生成

**YAML**:
```yaml
when:
  mock_response: "simple_response.json"
```

**生成的代码**:
```rust
if let Some(mock) = env.mock_server() {
    mock.setup_streaming_response(vec!["Response"]).await.unwrap();
}
let output = env.run_cli(&["hello"]).await.unwrap();
```

### 5. Then 阶段生成

**YAML**:
```yaml
then:
  assert_success: true
  assert_contains: "Hello"
  assert_match: "Hello.*World"
  assert_tool_called: "bash"
```

**生成的代码**:
```rust
output.assert_success();
output.assert_contains("Hello");
output.assert_match(r"Hello.*World");
output.assert_tool_called("bash");
```

## 完整生成示例

### 输入 YAML

```yaml
test_suite:
  name: "基础 CLI 测试"
  description: "测试 CLI 基础功能"

  tests:
    - name: "帮助命令"
      description: "验证 help 命令显示帮助信息"
      given:
        args: ["help"]
      then:
        assert_success: true
        assert_contains: "Usage"

    - name: "简单对话"
      description: "测试 AI 对话功能"
      given:
        args: ["hello"]
      when:
        mock_response: "simple_response.json"
      then:
        assert_success: true
        assert_contains: "Hello"
```

### 输出 Rust 代码

```rust
// Generated by build.rs
// DO NOT EDIT MANUALLY
// Original source: tests/suite
// Suite: 基础 CLI 测试

use crate::tests::common::*;

#[tokio::test]
#[serial_test::serial]
async fn test_bang_zhu_ming_ling() {
    // 验证 help 命令显示帮助信息
    let mut env = TestEnv::new().await.unwrap();
    let output = env.run_cli(&["help"]).await.unwrap();
    output.assert_success();
    output.assert_contains("Usage");
}

#[tokio::test]
#[serial_test::serial]
async fn test_jian_dandui_hua() {
    // 测试 AI 对话功能
    let mut env = TestEnv::with_mock().await.unwrap();
    if let Some(mock) = env.mock_server() {
        mock.setup_streaming_response(vec!["Response"]).await.unwrap();
    }
    let output = env.run_cli(&["hello"]).await.unwrap();
    output.assert_success();
    output.assert_contains("Hello");
}
```

## 高级特性

### 1. 函数名去重

自动处理重复的测试名称：

```yaml
tests:
  - name: "测试输出"
  - name: "测试输出"
  - name: "测试输出"
```

生成：
```rust
async fn test_ce_shu_shu_chu() { ... }
async fn test_ce_shu_shu_chu_2() { ... }
async fn test_ce_shu_shu_chu_3() { ... }
```

### 2. 条件编译

生成的测试仅在测试模式下编译：

```rust
#[cfg(test)]
mod tests {
    use crate::tests::common::*;

    #[tokio::test]
    #[serial_test::serial]
    async fn test_example() { ... }
}
```

### 3. 自动 mod.rs 生成

生成器自动更新 `tests/generated/mod.rs`：

```rust
// Generated by build.rs
// DO NOT EDIT MANUALLY

pub mod cli_basic;
pub mod cli_simple;
pub mod config_precedence;
// ... 其他模块
```

## 错误处理

### YAML 解析错误

```bash
cargo build --package ifainew

# 输出：
# warning: ifainew@0.4.4: 正在生成测试代码...
# warning: ifainew@0.4.4: 测试生成失败: Parse error: ... at line 10
# warning: ifainew@0.4.4: 提示: 运行 `cargo run --bin generate_tests` 手动生成
```

**解决方案**:
1. 检查 YAML 语法
2. 使用在线 YAML 验证器
3. 运行 `cargo run --bin generate_tests` 查看详细错误

### 文件写入错误

```bash
# 输出：
# warning: ifainew@0.4.4: 测试生成失败: Permission denied
```

**解决方案**:
1. 检查 `tests/generated/` 目录权限
2. 确保目录可写：`mkdir -p tests/generated/`

### 中文函数名过长

```bash
# 输出：
# warning: function name exceeds 50 characters
```

**解决方案**:
1. 使用更短的测试名称
2. 修改 `MAX_FUNCTION_NAME_LENGTH` 常量

## 性能优化

### 增量生成

生成器使用 `cargo:rerun-if-changed` 监听 YAML 文件：

```rust
// build.rs
println!("cargo:rerun-if-changed=src/bin/ifai/tests/suite");
println!("cargo:rerun-if-changed=src/bin/ifai/tests/generate_tests.rs");
```

只有修改的 YAML 文件会触发重新生成。

### 并行生成

生成器支持并行处理多个 YAML 文件：

```rust
use rayon::prelude::*;

for entry in fs::read_dir(&suite_dir)?.par_iter() {
    // 并行生成测试代码
}
```

### 缓存机制

生成的代码会被 Cargo 缓存，避免重复编译：

```bash
# 首次编译：~30 秒
cargo build --package ifainew

# 未修改 YAML：~1 秒（使用缓存）
cargo build --package ifainew
```

## 最佳实践

### 1. 避免手动修改生成的代码

生成的文件头部有警告：

```rust
// Generated by build.rs
// DO NOT EDIT MANUALLY
```

如果需要自定义逻辑，修改 YAML 或生成器逻辑。

### 2. 版本控制

将生成的代码提交到版本控制：

```bash
git add src/bin/ifai/tests/generated/
git commit -m "test: update generated tests"
```

这样可以：
- 审查生成的代码
- 快速发现生成问题
- 避免生成器 bug 影响所有开发者

### 3. 持续集成

在 CI 中验证生成的代码：

```yaml
# .github/workflows/test.yml
- name: Verify generated tests
  run: |
    cargo run --bin generate_tests
    git diff --exit-code src/bin/ifai/tests/generated/
```

## 故障排除

### 问题：生成的代码不编译

**症状**:
```
error: expected identifier, found `@`
```

**原因**: 测试名称包含特殊字符

**解决方案**:
```yaml
# ❌ 错误
name: "测试@#$"

# ✅ 正确
name: "测试特殊字符"
```

### 问题：Mock 响应文件找不到

**症状**:
```
error: file not found: simple_response.json
```

**原因**: Mock 响应文件路径错误

**解决方案**:
```yaml
# ❌ 错误
when:
  mock_response: "wrong_path/response.json"

# ✅ 正确
when:
  mock_response: "simple_response.json"
```

### 问题：测试函数名冲突

**症状**:
```
error: duplicate definition
```

**原因**: 手动添加了与生成函数同名的函数

**解决方案**: 删除手动添加的函数，或修改 YAML 测试名称
